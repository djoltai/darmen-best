## 2026-07-14 (2) — code review всего проекта: фиксы багов в лабах

**Что сделано.** Ревью всех ~8k строк src (страницы и компоненты — вручную,
скрипты двух лабов — двумя параллельными ревью-агентами, все находки
перепроверены вручную и в браузере). Исправлено:

- **exam-p-monty-hall/screen2.ts:** переключение тумблера «знает/наугад»
  во время бегущего прогона 1000 не останавливало `setInterval` — интервал
  дописывал в сброшенные карточки статистику-смесь двух режимов. Теперь
  `setMode` обрывает прогон (id интервала поднят в scope, паттерн как у
  `heroAnim`). Проверено в браузере: прогон умирает на переключении,
  новый прогон в новом режиме работает.
- **exam-p-monty-hall/screen1.ts:** таймер гашения чипа вскрытой шкатулки
  (660 мс) не отменялся — при быстром «Поменять/Остаться» устаревший
  таймер прятал перерисованный чип «0» в фазе result. Теперь id хранится
  и снимается в `render()`. Оба сценария (быстрый и штатный) проверены.
- **frm-var.astro (шторка, п. 4) + комментарий charts.ts:** формула
  `Mean(X_T) = e^{(μ+σ²/2)T} ≈ $131` была численно неверна — эта
  лог-нормальная аппроксимация даёт ≈$186; $131 — это точное
  `(E[R])^T = 1.05^100` (код в charts.ts всегда считал правильно, ошибка
  только в тексте/комментарии). Заменено на точную формулу, punchline
  σ²/2 сохранён через разрыв показателей `ln E[R] − μ ≈ σ²/2`.
- **frm-vol-drag/charts.ts:** траектории all-in не клипались по плоту —
  глубоко-убыточные пути (log10 < −7; с 30 фоновыми сценариями это
  десятки процентов загрузок) рисовались поверх нижней оси и подписей.
  Добавлен clip по образцу drawTrajectorySlider; финальная точка — вне
  клипа, чтобы не резалась на правом краю.
- **frm-vol-drag/main.ts:** resize во время 2.2-сек анимации рисовал
  полную траекторию (спойлер финала) с откатом на следующий кадр. В
  resize-обработчике перерисовка активной траектории пропускается при
  `isPlaying` (кадры и так идут каждые 22 мс).
- **KaTeX-бутстрап (frm-var, exam-p-monty-hall):** ретрай каждые 50 мс
  стал конечным (~10 с) — раньше при недоступном CDN таймер жил вечно.
- Мелочь: LinkedIn в футере главной приведён к `www.` (как везде),
  ссылка «пост-анонс» в финале frm-var получила `target="_blank"
  rel="noopener noreferrer"` как у трёх соседних.

**Мёртвый код — замечен, НЕ удалён** (правило «упомянуть, не удалять»):
`charts.ts` `COL.text` не используется; `coin.ts` ветки `v>=1` и `v>=0.01`
идентичны, ветка `lv>=4` в `fmtAxisTick` недостижима; `dist.ts`
`generateTraj` экспортируется, но извне не импортируется; атрибут
`data-post-anchor` в frm-var.astro нигде не читается.

**Отмечено на будущее:** `calc.ts::simulate()` покрыт тестами, но UI
дублирует цикл инлайном (ради поэтапной анимации) — тесты защищают только
референс-копию; a11y-долг: `.mh-box`/`.mh-cell` — div'ы с onclick, с
клавиатуры манипулировать нельзя (кнопки прогонов при этом настоящие
`<button>`); typecheck прогнать нечем — typescript не в dep'ах (Astro 6
сам его не тянет), vitest по-прежнему ждёт установки.

**Проверка.** `npm run build` чистый; все фиксы проиграны в браузере
(Playwright): тумблер посреди прогона, быстрый decide, прогон 1000 в
обоих режимах, KaTeX-рендер новой формулы, клип на реально выпавшем
глубоко-убыточном пути, двойной resize во время анимации. Консоль — ноль

## 2026-05-18 (вечер) — LabCard: чарт под лаб-превью

**Что сделано.**

- Чарт в `src/components/LabCard.astro` переписан с 12-траекторного «пучка»

  11 возможных путей (серое облако, opacity 0.10), одна активная

- Та же монетка что в лабе (×1.5/×0.6, p=0.5), всё в frontmatter,
  без `Math.random`, byte-stable. viewBox 320×200, Y log-scale `[10⁻⁴, 10²]`
  (6 декад) — достаточно для all-in lognormal-облака без мёртвых полей.
- Цвет активной — по **зоне**, не по шагу: midpoint сегмента ≥ $1 → teal,
  < $1 → coral. Та же конвенция что в лабовском `charts.ts:127-129`.
- Сюжет seed=173: ~49/100 шагов над $1, max ~$11 в пике, финал $0.005
  (медиана lognormal'и). Длинный teal-кусок слева → длинный coral-спуск
  справа → end-dot coral у дна. «Volatility Drag в одном кадре».
- Деплой по плану: push ветки → Vercel preview success → merge `--no-ff`
  в main → push main → production success на darmen.best.

**Что узнали / решения.**

- **План — ориентир, не догма.** Plan-doc спецификации
  (`claude-md-roadmap-md-gentle-yeti.md`) предлагал «две аналитические
  кривые: gray decay + teal smoothstep climb». Реализовали — на скриншоте
  «непонятно что и о чём». Юзер попросил вместо абстракции взять напрямую
  вид лаба после броска. Решение: смотреть скриншот лаба → понять
  компоненты → портировать их в frontmatter SVG. Пивот через 2 итерации.
- **Цветовая семантика «по шагу» = RG-светофор-эффект.** Сначала окрашивал
  каждый сегмент по направлению шага (win × 1.5 → teal, loss × 0.6 → coral).
  Сегмент ~3px по X → мерцание teal/coral каждые 3 пикселя → визуально
  «генерик финансовый светофор». Переключение на «по зоне» дало длинные
  непрерывные сегменты + семантика «герой в зоне прибыли/убытка»
  информативнее «этот шаг выиграл/проиграл».
- **CSS-vars в SVG резолвятся правильно — это субъективное восприятие.**
  Юзер сказал «цвета не наши». Пиксельная выборка из скриншота показала
  ровно `#07434B` и `#C75B4F` (= `--teal`, `--coral`). Уточнение: жалоба
  была про семантику окраски, не палитру.
- **Один seed с clamping убивает облако.** Seed=111 при N=100 →
  max $16994 → clamp в верхнюю рамку 69 шагов подряд → жирная
  горизонталь у потолка ломала композицию. Алгоритмический отбор seeds
  по критериям (max ≤ 50, баланс зон 25-75/100, разумные zone-flips) —
  быстрый способ найти «зрелищный» путь.
